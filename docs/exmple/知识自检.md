# 记忆

## **识别、回忆、列举、描述**：

定义、概念、术语、事实、逻辑链等等，用自己的话描述可也助于理解

**方法**：复述、复习笔记、闪卡、大声背诵朗读、记忆术\法

**检验**：复述、选择题、匹配题、填空题

**评价**：人脑数据库基础，金字塔的最底端

# 理解

**解释、概述、转述**：

用自己方式说明解释和描述记忆的内容、核心概念
**多角度**视角，**多层面**描述解释，不同方向的类比[^例子][^费曼技巧]

## **解释、举例、分类、总结、推断、比较、说明、描述、归纳、转换**

**方法**：
做摘要、举例书面、类比对比相似概念、向他人讲解

# 应用

在新情境中用所学解决问题

## **运用、解决、计算、操作**

**方法**：做练习、项目、应用题。执行步骤，模仿、演示

# 分析

分解解构材料，厘清各部分关系与解构

## **区分、组织、归因、解构**

**方法**：绘制**结构图**、区分**事实与观点**、辨析**因果关系**、对比**不同体系**

**例子**：撰写分析报告、做要素对比、找逻辑谬误等
