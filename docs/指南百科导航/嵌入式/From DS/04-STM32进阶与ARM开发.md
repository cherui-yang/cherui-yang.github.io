# 04 - STM32 进阶与 ARM 开发

> 预计时间：4-6 个月  
> 目标：掌握主流 32 位 MCU 开发，能够独立完成带多个外设的中等复杂度项目

## 1. 开发板与工具链

### 推荐开发板

- **入门级**：STM32F103C8T6（“蓝色药丸”，约 ¥50-80） + ST-Link 下载器
- **进阶**：STM32F407 或 GD32H7（Cortex-M7 高性能内核）
- **国产替代**：GD32（兆易创新）、AT32（雅特力）

### 开发环境

- **IDE**：Keil MDK（教程最多）或 STM32CubeIDE（官方免费）
- **配置工具**：STM32CubeMX（生成初始化代码）
- **调试器**：ST-Link、J-Link、DAP-Link

## 2. 必须掌握的外设与协议

| 外设/协议          | 重要程度 | 说明                             |
| ------------------ | -------- | -------------------------------- |
| GPIO               | ⭐⭐⭐⭐⭐    | 输入输出、上下拉、开漏/推挽      |
| 中断 (EXTI)        | ⭐⭐⭐⭐⭐    | 外部中断、中断优先级配置（NVIC） |
| 定时器 (TIM)       | ⭐⭐⭐⭐⭐    | 基本定时、PWM 输出、输入捕获     |
| USART/UART         | ⭐⭐⭐⭐⭐    | 异步串行通信（与 PC/模块通信）   |
| I2C                | ⭐⭐⭐⭐⭐    | 读写 EEPROM、传感器、OLED        |
| SPI                | ⭐⭐⭐⭐⭐    | 高速通信（LCD、SD 卡、Flash）    |
| ADC                | ⭐⭐⭐⭐     | 模拟电压采集                     |
| DMA                | ⭐⭐⭐⭐     | 不占用 CPU 的数据搬运            |
| 看门狗 (IWDG/WWDG) | ⭐⭐⭐      | 系统稳定性                       |

## 3. 学习方法

1. **用 STM32CubeMX 生成一个 LED 闪烁工程**，理解时钟树配置
2. **手写寄存器版本**（可选）：尝试直接操作 `RCC`, `GPIO` 寄存器点亮 LED
3. **标准库 / HAL 库开发**：重点学习 HAL 库的 callback 机制
4. **每个外设单独练习**，然后组合使用（例如：串口中断接收命令，控制 PWM 占空比）

### 🛠️ 项目推荐（由易到难）

- 按键控制 LED 与蜂鸣器（中断方式）
- 串口打印温湿度传感器数据（DHT22 / I2C 传感器）
- 基于 PWM 的电机调速（直流电机 + 编码器反馈）
- OLED 显示 ADC 采集的电压波形（简易示波器）
- SD 卡 + FATFS 文件系统记录数据
- **平衡小车**（MPU6050 姿态解算 + PID 控制 + 直流电机）
