# 07 - 进阶方向与专题

> 完成主干路线后，可根据兴趣选择以下一个或多个方向深入研究

## 1. 嵌入式 AI / TinyML

将机器学习模型部署到资源受限的边缘设备。

### 算力参考
- 0.1-0.5 TOPS：关键词唤醒、异常检测
- 1-5 TOPS：人脸识别、目标检测

### 硬件平台
- ELF-RV1126B（3 TOPS NPU，RK 芯片）
- Kendryte K210（老牌边缘 AI）
- STM32N6（ST 最新 NPU 系列）

### 学习路线
- TensorFlow Lite Micro
- 模型量化与剪枝
- NPU 驱动调用（RKNN、NCCL）

## 2. 物联网（IoT）开发

- **无线协议**：WiFi（ESP8266/ESP32）、BLE、Zigbee、LoRa
- **网络协议**：MQTT、CoAP
- **云平台**：阿里云 IoT、华为云 IoT、AWS IoT Core

### 推荐硬件
- ESP32-C3 / ESP32-S3（WiFi + BLE，支持 Arduino/ESP-IDF）

## 3. 机器人操作系统（ROS）

广泛应用于机器人、自动驾驶。

- ROS 1（Noetic）/ ROS 2（Humble）
- 话题、服务、动作
- 常用工具：Rviz、Gazebo

### 入门项目
- 使用 TurtleBot3 仿真完成 SLAM 导航
- 编写自定义消息控制机械臂

## 4. 鸿蒙系统（OpenHarmony）

国产分布式操作系统，面向 IoT 与智能终端。

- LiteOS 内核（类似 RTOS）
- 鸿蒙驱动框架（HDF）
- 轻量级系统（Hi3861）与标准系统（RK3568）

## 5. RISC-V 架构

开源指令集架构，未来嵌入式的重要方向。

- 学习 RISC-V 指令集（RV32I）
- 在 SiFive Learn 或 QEMU 上运行裸机程序
- 购买全志 D1 / 平头哥玄铁 910 开发板

## 6. 安全与功能安全

- 固件加密、安全启动
- 常见漏洞（缓冲区溢出、侧信道攻击）
- 功能安全标准（ISO 26262，IEC 61508）
