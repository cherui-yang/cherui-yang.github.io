# 00 - 前言与导读

## 为什么选择嵌入式？

嵌入式系统是**软件与硬件深度协同**的技术领域，广泛存在于智能手机、智能汽车、工业机器人、医疗设备、可穿戴设备等几乎所有智能设备中。据预测，2025 年关键软件领域人才新增缺口超过 80 万，其中嵌入式软件人才需求尤为突出，岗位需求同比增长 **37%**。

- **应届本科薪资**：10K-15K/月
- **一线城市资深工程师**：可达 20K+/月

相比纯软件开发，嵌入式工程师需要同时掌握代码与硬件，入门门槛更高，但**职业护城河也更宽**。

- 包含面试高频题与职业发展路径

## 学习建议

1. **循序渐进**：不要颠倒顺序（硬件 → 裸机 → RTOS → Linux）
2. **理论 + 实践**：每学一个知识点，立即做一个小项目
3. **善用社区**：21ic、EEWorld、CSDN 等论坛有大量解决方案
4. **阅读芯片手册**：这是嵌入式工程师的核心技能
5. **保持耐心**：嵌入式学习曲线陡峭，坚持 12-18 个月必有收获
