# 10 - 面试准备与职业发展

## 面试高频题分类

### C 语言

1. `static` 关键字的作用（局部静态变量、全局静态限制作用域、静态函数）
2. `volatile` 用在哪些场景？（中断、硬件寄存器、多线程共享变量）
3. 指针常量和常量指针的区别
4. 内存对齐的原因与 `#pragma pack` 效果
5. 堆与栈的区别（分配方式、大小、碎片）

### 操作系统 / RTOS

1. 中断服务函数中能否调用 `printf`？为什么？（不可重入、阻塞）
2. FreeRTOS 中二值信号量与互斥量的区别
3. 优先级反转是什么？如何解决？
4. 任务间通信有哪些方式？（队列、事件组、通知、全局变量+关中断）

### Linux

1. 用户空间与内核空间通信方式（系统调用、netlink、procfs、mmap）
2. 进程与线程的区别（资源、切换开销、通信方式）
3. 僵尸进程与孤儿进程
4. 字符设备驱动中的 `open`, `read`, `write` 被调用时内核发生了什么？
5. 设备树的作用（描述硬件，避免硬编码）

### 硬件与协议

1. I2C 与 SPI 的优缺点比较（引脚数、速度、主从数量）
2. 中断处理的上半部与下半部（tasklet、workqueue）
3. DMA 如何工作？（请求、响应、传输完成中断）
4. 看门狗溢出时间如何计算？
