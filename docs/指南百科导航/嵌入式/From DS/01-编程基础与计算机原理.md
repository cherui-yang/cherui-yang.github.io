# 01 - 编程基础与计算机原理

> 预计时间：2-3 个月  
> 目标：掌握 C 语言（特别是指针、内存管理）并理解计算机如何执行代码

## 1. C 语言编程

嵌入式开发的绝对核心语言。你需要熟练掌握：

- 基本语法（数据类型、运算符、流程控制）
- 数组、函数、作用域
- **指针**（一级指针、二级指针、指针与数组、指针与函数）
- **动态内存管理**（malloc/free，堆与栈的区别）
- 结构体、联合体、枚举
- 预处理指令（#define、#ifdef）
- 文件操作

### 📘 推荐书籍

- 《C Primer Plus》（入门首选）
- 《C 和指针》（指针专项深入）
- 《C 陷阱与缺陷》
- 《C 专家编程》（“C 语言三剑客”）

### 🎥 视频课程

- 翁恺 C 语言（B 站，生动有趣）

### 🛠️ 实践项目

- 命令行学生成绩管理系统（数组 + 结构体）
- 简易通讯录（动态内存 + 文件读写）
- 链表实现的任务列表

## 2. 计算机组成原理（基础）

目标：理解 CPU、内存、总线、寄存器、中断等概念，明白软件与硬件如何协同工作。

### 必学内容

- 冯·诺依曼结构与哈佛结构
- CPU 流水线基本概念
- 内存层次（寄存器、Cache、RAM、ROM）
- 中断机制（中断向量表、中断优先级）
- 外设访问方式（端口映射、内存映射）

### 📘 推荐书籍

- 《深入理解计算机系统》（CSAPP）前 4 章（数据表示、机器级编程、处理器体系结构）

> 如果时间紧张，至少阅读 CSAPP 第 1、3 章，理解汇编与 C 的关系。

## 3. 可选：数据结构与基础算法

虽然不是嵌入式面试最侧重的点，但掌握以下内容有助于编写高效代码：

- 数组、链表、栈、队列
- 排序（冒泡、快排）
- 查找（二分查找）

推荐书籍：《大话数据结构》或《算法图解》。
