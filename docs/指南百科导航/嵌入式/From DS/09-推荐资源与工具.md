## 工具与软件

- **IDE/编辑器**：Keil, IAR, STM32CubeIDE, VS Code + EIDE 插件

- **版本控制**：Git + GitHub/Gitee
- **文档**：Dash (macOS) / Zeal (Windows) 离线查阅芯片手册
