# 02 - 电子电路基础

> 预计时间：2 个月  
> 目标：能看懂原理图，会使用万用表、示波器，理解基本电子元件和数字逻辑

## 1. 电路基础

### 元件特性

- 电阻、电容、电感
- 二极管（发光二极管、稳压二极管）
- 三极管（NPN/PNP，开关作用）
- MOSFET 基本应用

### 基本定律

- 欧姆定律、基尔霍夫电压/电流定律
- RC 充放电电路

### 工具使用

- 万用表（测电压、电阻、通断）
- 示波器（看波形，测量频率、占空比）
- 信号发生器（可选）

## 2. 数字电路

### 逻辑门

- 与门、或门、非门、异或门
- 真值表与布尔代数

### 组合逻辑电路

- 译码器（3-8 译码器）
- 多路选择器
- 加法器

### 时序逻辑电路

- SR 锁存器、D 触发器
- 计数器、移位寄存器

### 📘 推荐书籍

- 《电子技术基础（数字部分）》（康华光或阎石版）

### 🛠️ 仿真工具

- Multisim（电路仿真）
- Proteus（单片机 + 电路联合仿真）
- Tina-TI（TI 官方工具，免费）

## 3. 焊接与调试

- 学习使用电烙铁、焊锡、松香
- 练习焊接直插元件和 0805 贴片元件
- 能够根据原理图焊接一个简单的 LED 闪烁电路

> 如果不想买焊台，可以先买一块面包板 + 跳线 + 元件做实验。
