# 05 - RTOS 实时操作系统

> 预计时间：2-3 个月  
> 目标：理解实时系统的概念，能够在 STM32 上运行 FreeRTOS 或 RT-Thread，并用多任务解决实际问题

## 1. 为什么需要 RTOS？

裸机编程的主循环 + 中断在复杂项目中难以维护，RTOS 提供：
- 任务调度（抢占式/时间片）
- 任务间同步（信号量、互斥量、消息队列）
- 软件定时器
- 低功耗管理

## 2. 主流的嵌入式 RTOS

| RTOS      | 特点                         | 适用场景                 |
| --------- | ---------------------------- | ------------------------ |
| FreeRTOS  | 市场占有率最高，开源，轻量   | 通用 MCU 项目            |
| RT-Thread | 国产，组件丰富，有物联网组件 | 需要快速开发的 IoT 项目  |
| Zephyr    | Linux 基金会支持，支持多架构 | 较复杂的物联网系统       |
| ThreadX   | 微软开源，安全认证多         | 高安全领域（汽车、医疗） |

**学习建议**：先学 FreeRTOS，再了解 RT-Thread 的组件生态。

## 3. 核心概念与 API

### 任务管理

- `xTaskCreate()` 创建任务
- `vTaskDelay()` / `vTaskDelayUntil()` 延时
- 任务优先级与抢占

### 同步与通信

- 二值信号量 / 计数信号量（任务同步）
- 互斥量（解决优先级反转）
- 消息队列（任务间传递数据）
- 事件组（多条件等待）

### 中断管理

- 中断中如何使用信号量/队列（`xSemaphoreGiveFromISR()`）

## 4. 实践步骤

1. 在 STM32 上移植 FreeRTOS（可使用 CubeMX 一键生成）
2. 创建两个任务：一个 LED 闪烁，一个串口打印计数
3. 用信号量同步：按键中断释放信号量，任务收到后执行动作
4. 用消息队列：任务 A 采集 ADC 值，发送给任务 B 显示在 OLED 上
5. 模拟优先级反转问题，并使用互斥量解决

### 🛠️ 综合项目

- **多任务平衡小车**：姿态解算任务（高优先级）、PID 控制任务、遥控指令接收任务、日志记录任务
- **智能家居网关**：传感器采集任务、屏幕显示任务、MQTT 上传任务（配合 ESP8266）
