## 通信协议

| 协议     | 物理层      | 速度         | 常用场景          |
| -------- | ----------- | ------------ | ----------------- |
| UART     | 异步串行    | 115200bps    | 调试、GPS、蓝牙   |
| I2C      | 双线开漏    | 100k-400kHz  | 传感器、EEPROM    |
| SPI      | 四线全双工  | 几十 MHz     | LCD、SD 卡、Flash |
| CAN      | 差分双线    | 1Mbps        | 汽车、工业总线    |
| Ethernet | 双绞线/光纤 | 10/100/1000M | 网络通信          |
