# 嵌入式自学指南（2026版）

> 一份系统、全面、贴近实战的嵌入式学习路线与资源合集  
> 结构参考 [CS 自学指南](https://csdiy.wiki)，适合中文学习者

本仓库旨在帮助嵌入式爱好者从零开始，逐步掌握**硬件基础 → 裸机编程 → RTOS → 嵌入式 Linux** 的全栈能力。无论你是电子/计算机相关专业学生，还是转行的软件工程师，都可以按顺序学习。

## 📌 学习路线图（12-18个月）

| 阶段 | 内容                       | 预计时间 |
| ---- | -------------------------- | -------- |
| 0    | 编程基础 + 计算机原理      | 2-3个月  |
| 1    | 电子电路基础               | 2个月    |
| 2    | Arduino 入门               | 1-2个月  |
| 3    | STM32 + ARM 进阶           | 4-6个月  |
| 4    | RTOS（FreeRTOS/RT-Thread） | 2-3个月  |
| 5    | 嵌入式 Linux               | 3-4个月  |

详细说明请阅读各章节。

## 🚀 快速开始

如果你是**零基础**，请从 [01-编程基础与计算机原理](./01-编程基础与计算机原理.md) 开始。  
如果你已有 C 语言和电路基础，可以直接跳到 [03-单片机入门](./03-单片机入门-Arduino.md) 或 [04-STM32进阶](./04-STM32进阶与ARM开发.md)。

## 📚 推荐先修

- 基本的电脑操作能力
- 一台 Windows/Linux/Mac 电脑
- 购买一块入门级开发板（见 [09-推荐资源](./09-推荐资源与工具.md)）
