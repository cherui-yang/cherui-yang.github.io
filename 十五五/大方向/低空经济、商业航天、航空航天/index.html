    低空经济 + 商业航天：产业链、专业与岗位全景拆解

    低空经济 + 商业航天 = 空天产业。航空航天被写入了政府工作报告，被定义为“新兴支柱产业”。低空经济是在距地面3000米以下的空域，用无人机、eVTOL（电动垂直起降飞行器，俗称“空中出租车”）等飞行器做物流、载人、巡检等场景的经济活动。商业航天则是把造火箭、发卫星、卫星联网这些过去由国家干的事情，开放给民营企业来做，形成市场化产业链。两个产业共享底层技术——材料、动力、控制、通信、导航定位，底层完全相通。

    市场体量：低空经济2025年市场规模预计突破1.5万亿元，到2035年有望达3.5万亿元；商业航天2025年全产业链市场规模预计突破2.5万亿元。

    一、低空经济产业链

    低空经济产业链分为上游、中游、下游、支撑体系四大类，细分为18个子类，涵盖从原材料到应用服务的全链条。

    （一）上游：原材料、零部件与研发

    干什么的：造飞行器需要的“原料+零件+大脑”，决定飞行器能不能飞起来、飞得好不好。

    生态位： - 金属材料与复合材料：造机身骨架、机翼等，代表企业包括航材股份、航玻新材等，主要提供铝合金、碳纤维、钛合金等轻量化材料。 - 动力电池：eVTOL和大型无人机的“心脏”，核心企业有宁德时代、欣旺达、中创新航。 - 飞控与导航系统：飞行器的“大脑+小脑”，负责飞行姿态控制和路线规划。代表企业有边界智控（飞控+导航）、丰飞智控。 - 感知与芯片：飞行器的“眼睛+耳朵”，包括毫米波雷达芯片、视觉芯片、定位感知模组。代表企业有导远科技、肇观电子等。 - 核心设备与系统：包括航电系统、通信链路等，代表企业有航新科技、安达维尔等。 - 研发创新与仿真设计：为飞行器提供概念设计、气动仿真、结构优化等技术服务。

    适配的专业（[专业名]格式）：

    1. 材料科学与工程——搞轻量化机身材料（碳纤维、钛合金、航空铝合金）的研发与检测。
    2. 新能源科学与工程——研发高能量密度电池，解决eVTOL和无人机的续航难题。
    3. 电子信息工程——设计飞控系统、航电设备、通信链路。
    4. 自动化——开发飞行控制算法、导航与控制一体化系统。
    5. 电气工程及其自动化——研发电机、电驱系统，搞定飞行器的动力电控。
    6. 测绘工程——参与无人机航测的传感器选型与数据采集方案设计。

    适配的公司/企业（附岗位与职责） ⬇️

    ① 宁德时代 - 岗位：eVTOL电池研发工程师 - 干什么的：研发适用于eVTOL的高能量密度电池系统，解决高倍率充放电、长循环寿命和安全性问题，配合峰飞航空等客户完成电池系统集成测试。

    ② 边界智控 - 岗位：飞控系统研发工程师 - 干什么的：设计并开发eVTOL飞行控制算法（姿态控制、轨迹规划），实现飞控系统的软硬件集成，完成系统仿真验证与试飞测试。

    ③ 航材股份 - 岗位：航空材料工程师 - 干什么的：研发用于飞行器结构件的轻量化金属与复合材料（钛合金、铝锂合金、碳纤维等），进行材料的力学性能测试与适航取证。

    二、商业航天产业链

    商业航天产业链分为上游制造、中游发射与运营、下游应用三大环节。可类比为“淘金产业生态”：上游“卖铲子”，中游“送淘金客上路”，下游“把金子变成商品”。

    （一）上游：火箭/卫星制造及配套

    干什么的：造火箭、造卫星，以及所有配套的核心零部件和材料。

    生态位： - 火箭制造：包括火箭结构/骨架（特种材料、3D打印零部件）、火箭发动机（液体火箭发动机、固体火箭发动机）、航电与控制系统等。代表企业有蓝箭航天（液氧甲烷火箭）、星河动力（固体火箭）、中科宇航（亚轨道飞行器）等。 - 卫星制造：包括卫星平台（结构、热控、电源、姿控等）和有效载荷（通信转发器、遥感相机、导航载荷等）。代表企业有中国卫星（小卫星批产）、银河航天（通信星座）、长光卫星（遥感星座）、微纳星空（微小卫星平台）。 - 关键配套：特种气体/液氢燃料（如九丰能源）、高端轴承（如国机精工）、3D打印零件（如铂力特）、星载芯片（如铖昌科技）、航天电子系统（如航天电子）等。 - 地面设备制造：包括卫星测控站、信关站、移动终端天线等。

    适配的专业：

    1. 飞行器设计与工程——火箭总体设计、弹道规划，或卫星总体设计、结构力学分析。
    2. 飞行器动力工程——液体/固体火箭发动机设计与测试、推进剂研发。
    3. 航空航天工程——航天器多学科综合设计与集成，系统工程方法论。
    4. 机械工程——火箭/卫星精密机械结构设计、3D打印制造工艺。
    5. 电子信息工程——星载电子系统（测控、通信、计算机）设计与集成。
    6. 材料科学与工程——航天级特种材料（耐高温、抗辐射、轻量化复合材料）研发。

    三、低空经济 × 商业航天：融合交汇点

    低空经济与商业航天并非两个孤立的赛道，它们在产业链多个环节存在深度交叉与协同：

    1. 技术共享层

    航空航天被统筹纳入同一个产业范畴，二者在材料、动力、控制、通信、导航定位等底层技术上具备高度相通性。造eVTOL的复合材料、飞控芯片，和造卫星的结构件、星载计算机有大量的技术复用空间。

    2. 空域与基础设施协同

    低空经济需要低空的通信、导航、监视基础设施，而商业航天的卫星互联网可以为低空飞行器提供全球覆盖的通信与高精度导航增强服务。北斗+低轨星座=为低空飞行器提供厘米级定位。

    3. 数据融合应用

    卫星遥感数据+无人机近地采集数据=“天上看+地上巡”的立体化监测体系，在农业、环保、应急等领域具有巨大协同价值。

    4. 人才需求共性

    两个产业都需要大量“交叉复合型”人才——既要懂航空航天硬技术，又要懂AI算法、通信网络、商业运营。低空经济领域复合型人才占比需求高达60%以上。商业航天同样不仅需要专业技术人才，更需要懂市场、懂行业、懂应用的复合型人才。

    四、全局视角：为什么要把这两个产业合起来看？

    1. 共享底层技术：航空与航天在材料科学、空气动力学、推进技术、控制理论、通信导航等基础学科上高度共通。造火箭发动机的技术能力和造eVTOL电推进系统的工程能力在方法论上是相通的。
    2. 政策顶层定位一致：航空航天被整体定位为“新兴支柱产业”，低空经济也被明确纳入战略性新兴产业集群，二者在同一政策框架下协同发展。
    3. 产业链互补：商业航天的卫星互联网能为低空经济提供通信+导航基础设施；低空经济的无人机产业链则为小型化、低成本航天器提供了供应链基础。
    4. 人才流动空间广阔：在空天产业的大框架下，专业人才在两个领域的迁移成本极低，职业发展空间成倍放大。
    5. 应用场景融合加速：卫星遥感+低空无人机巡检、卫星通信+低空飞行器远程控制、太空算力+低空海量数据处理，融合创新空间正在打开。
